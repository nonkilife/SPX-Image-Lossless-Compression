# SPX Sharding Template Library

This document defines the authoritative set of **Adaptive Probability Distribution (PDF) Templates** for the SPX codec. These templates are assigned per-image based on the quantitative fingerprints obtained during the Pass 1 analysis.

## 1. Template Decision Matrix

| Template ID | Target Dataset | Core Strategy | V-Tiers | I-Tiers | T-Tiers | Total Shards |
| :--- | :--- | :--- | :---: | :---: | :---: | :---: |
| **CLIC-Elite-60** | CLIC | [EXPERIMENTAL] High-V/I Split | 8 | 4 | 2* | **60** |
| **Universal-42** | Default | [VERIFIED] Balanced Power-Law | 7 | 3 | 2 | **42** |
| **Gray-Fast-30** | Grayscale | Smooth-Zone Priority | 10 | 3 | 1 | 30 |

| Template ID | Designation | Decision Logic (Thresholds) | Primary Use Case |
| :--- | :--- | :--- | :--- |
| **A** | **Ultra-Smooth** | `H < 2.0` OR `Lag-1 AC > 0.98` | Synthetic graphics, clear sky, flat renders. |
| **B** | **Balanced** | `2.0 <= H < 3.4` AND `HES < 42%` | High-quality natural photos (CLIC baseline). |
| **C** | **Detailed** | `3.4 <= H < 4.1` AND `42% <= HES < 65%` | Textures, architecture, foliage (DIV2K common). |
| **D** | **Chaos** | `H >= 4.1` OR `HES >= 65%` | Pathological noise, extremely sharp edges (Hell/Hard).|
| **E** | **Granular** | `Hit Rate < 18%` AND `H < 4.0` | Fine film grain, sensor noise, scan textures. |

## 2. Technical Specifications

### Template A: Ultra-Smooth
*   **PDF Profile**: Narrow Laplacian (sigma < 0.8).
*   **Symbol Logic**: Zero-biased. Optimized for long-run RLE and Bit-plane skipping.
*   **Shard Bias**: Dominates Context IDs 0-2 (Flat tiers).

### Template B: Balanced Natural
*   **PDF Profile**: Standard Laplacian (sigma approx 1.25).
*   **Symbol Logic**: Balanced distribution.
*   **Shard Bias**: Balanced activity across Context IDs 3-29.

### Template C: Detailed / Textured
*   **PDF Profile**: Broad Laplacian (sigma approx 2.5).
*   **Symbol Logic**: Designed for "Heavy Tail" distributions where textures create significant residual energy.
*   **Shard Bias**: High weighting for Texture Tiers (V-Tiers 2-3).

### Template D: Chaos / Pathological
*   **PDF Profile**: Ultra-Broad / Quasi-Uniform.
*   **Symbol Logic**: Optimized for High-Entropy symbols. Minimizes escape-code frequency in extremely busy regions.
*   **Shard Bias**: Maximum deployment in Context IDs 30-41 (Edge/Trend tiers).

### Template E: Granular / Noisy
*   **PDF Profile**: "Noise-Centered" distribution.
*   **Symbol Logic**: Specifically handles high-frequency oscillation (AC decay) where MED hit rate is low but entropy is moderate.
*   **Shard Bias**: Targeted at Noise-Trigger Contexts.

## 3. Implementation Workflow

### Step 1: Rapid Fingerprint (Pre-pass)
*   Calculate **Lag-1 Autocorr**. 
*   If $> 0.98$, immediately assign **Template A** and proceed to Pass 2.

### Step 2: Full Analysis (Pass 1)
*   Perform MED Prediction.
*   Extract **Residual Entropy (H)** and **High-Energy Shard Ratio (HES)**.
*   Apply the Decision Matrix to find the matching Template ID.

### Step 3: Predictive Encoding (Pass 2)
*   Inject the assigned Template ID into the SPX header.
*   Use the corresponding PDF weights in the `rANS` or `Bit-plane` coder.


## 4. Default Shard Distribution (Universal-42)

The **Universal-42** profile is the standard shard mapping configuration for SPX. It segments statistical space into 42 distinct context buckets across 8 variance tiers.

### Tier Structure & Mapping
| Tier Category | Variance Tiers (V) | Shard ID Range | Segmentation Logic |
| :--- | :--- | :--- | :--- |
| **Flat / Base** | V = 0 | **0 - 2** | Segmented by **Intensity** (Dark, Mid, Light). Trend is ignored. |
| **Medium Variance** | V = 1, 2, 3 | **3 - 29** | Full Cross-product: **Intensity (3) × Trend (3)**. Total 27 shards. |
| **High Energy** | V = 4, 5, 6, 7 | **30 - 41** | **Trend-only** (3 trends per tier). Intensity is ignored to prevent sparsity. |

### Technical Feature Set
*   **Intensity Boundaries**: `[0, 60, 190, 255]`
*   **Variance Boundaries**: `[0, 1, 2, 4, 8, 16, 32, 255]`
*   **Context Feature Vector**: `[V_Tier:5 bits] | [Trend:2 bits] | [Noise:1 bit]`
*   **Dispatch Latency**: $O(1)$ via double-feature LUT (SPATIAL_TRANS_LUT).
*   **Verification (2026-04-24)**: Verified as the global optimum for photographic datasets (CLIC_2021). 
    - **Avg BPP**: 8.5180
    - **Throughput**: ~63 MB/s (Enc), ~74 MB/s (Dec)

### Default Template Alignment
*   **Template A** targets Shards 0-5.
*   **Template B/C** covers the Medium blocks (Shards 3-29).
*   **Template D** primarily optimizes the High-Energy Trend blocks (Shards 30-41).

## 5. CLIC-Elite-60 (Adaptive/Photographic)

Developed specifically for high-fidelity photographic datasets, the **CLIC-Elite-60** template maximizes directionality and intensity-aware context mapping.

### Tier Structure & Mapping
| Tier Category | Variance Tiers (V) | Shard ID Range | Segmentation Logic |
| :--- | :--- | :--- | :--- |
| **Smooth Base** | V = 0 | **0 - 3** | **Intensity-only** (4 Fibonacci tiers). Trend ignored. |
| **Texture & Ridge** | V = 1 to 7 | **4 - 59** | **Intensity (4) × Trend Sign (2)**. Total 56 shards. |

### Technical Feature Set
*   **Variance (V) Boundaries**: `[0, 1, 2, 4, 8, 16, 32, 255]`
*   **Intensity (I) Boundaries**: `[0, 34, 89, 144, 255]` (Fibonacci-based)
*   **Trend (T) Logic**: 
    - Mode 0 (V=0): Single T-tier (Neutral).
    - Mode 1 (V>0): Two T-tiers (`da - db < 0` vs `da - db >= 0`).
*   **Entropy Potential**: SSC ~2.486 BPP (approx. 20-30% better than Universal-42 on CLIC).

### Memory & SIMD Alignment
*   **Shard Total**: Exactly 60 (Fits within 64-slot cache lines for parallel decoding).
*   **LUT Footprint**: Compatible with standard 1MB Context LUT architectures.

### Research Note (2026-04-24)
> [!WARNING]
> **Performance Regression**: In full-scale benchmarking on CLIC_2021 (585 images), this template exhibited a **+0.5% BPP regression** compared to Universal-42.
> **Throughput Loss**: The increase to 60 shards results in a 3-5% drop in system throughput due to context sparsity and management overhead.
> **Status**: **Not Recommended** for production use in SPX v8.3.2.

## 6. Research Insights: Intensity Sensitivity
Monte Carlo simulations (100 trials) on the intensity axis revealed that the SPX engine is highly sensitive to shadow detail. While the default `[60, 190]` is extremely robust, a specialized "Shadow-Deep" split at `[37, 138]` showed potential for 0.01-0.03% gains on high-resolution targets, though the overhead of extra shards (66) generally negates this advantage.
